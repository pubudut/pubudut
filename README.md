## Featured open-source project

### 🤖 [DevAI — AI-Assisted Development Workspace](https://github.com/pubudut/Dev-AI-Assistant)

A **local terminal CLI and browser-based workspace** for AI-assisted development, code review, and unit-test generation. DevAI combines repository context, configurable skills, and model-provider integrations with a reviewable, human-controlled workflow.

**What it demonstrates**

- A shared workflow engine behind both CLI and web interfaces
- Support for Android, iOS, Java, Python, TypeScript, .NET, and other development profiles
- Integration options for GitHub Copilot, Copilot Enterprise CLI, Azure Foundry-compatible APIs, and Anthropic Messages
- Structured plans and reports, isolated Git worktrees, proposed patches, and explicit apply/ignore decisions
- Optional enterprise context through configured Jira, Confluence, and Git-host tooling

## How I think about architecture

> Start with the problem and the constraints. Make trade-offs explicit. Design for change, reliability, and the teams who will operate the system.

I care about architecture that is **understandable, measurable, and maintainable**—not complexity for its own sake. My approach combines system-level thinking with enough implementation depth to validate that a design will work in practice.
